# Smriti-Saathi

An interactive cognitive training and memory companion application.

🚀 **Live Deployment:** [https://hmahawar460.github.io/Smriti-Saathi/](https://hmahawar460.github.io/Smriti-Saathi/)

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   ```bash
   npm install
   ```
2. Set the `GEMINI_API_KEY` in `.env.local` to your Gemini API key
3. Run the app:
   ```bash
   npm run dev
   ```
